 In every difficulty the music stops after 3 missed faces in a row. Only missed faces count. The water drop and the badge do not.

The song plays when you catch 3 faces in a row, and continues where it stopped.

Buttons:
- **Quit to menu** (while playing) ends the run and goes back to the start screen.
- **Quit game** (on the start screen) closes the whole game. If your browser does not let the page close itself, it shows a goodbye screen and you can close the tab.
- **Next track** only works after you finish a song. Then it starts the next song of the same difficulty. It stays greyed out during a run and when the difficulty has only one song.
